# yidun/iconclick

网易易盾图标顺序点选识别模块。样本来自微博登录安全验证，不包含滑块、文字点选、旋转验证码，也不代表支持网易易盾的所有图标布局。

API：`Recognize(data []byte) ([]Match, error)`。输入 JPEG/PNG 编码字节，输出按提示顺序排列的三个目标，使用原始图片像素坐标。调用方自行决定如何处理匹配分数及结果。

当前布局固定为 480×360：顶部 480×240 为场景；底部第一行三个图标在 x=0、42、84，各取 30×30 模板。其他尺寸和空提示返回错误；相同尺寸但不同素材排列不能保证正确识别。

算法：提取提示形状，场景和模板减去高斯背景，枚举 1.3–1.7 倍缩放及每 5° 的旋转，取绝对归一化相关性最高的位置，兼容深浅色目标。匹配分数不是概率，低质量结果仍可能返回，调用方应根据自己的验收规则处理。

每次调用独立管理 OpenCV Mat 资源；不修改全局线程配置，不执行网络或浏览器操作。四组样本属于回归数据，不能用于推断独立测试成功率。
